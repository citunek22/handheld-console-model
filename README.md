# Handheld console

Its a custom 3D model of a particular handheld console that I designed from scratch in Onshape for Hack Club.

## About the project
I wanted to practice 3D modeling in Onshape so I made a handheld console. Also I added my own details:
Like 4 larger air vents on top instead of 6 small ones, swapped the `+` and `-` volume buttons, also I replaced the test on the slot with "Just a slot" // You know just for fun
Right now it's just the main body. I might model detachable side controllers later.

## Printing notes
Sorry yall I don't have a 3D printer yet, so I checked the model in PrusaSlicer to make sure it's printable. If you want to print it:
- Print it vertically (standing on the bottom edge or on the usb because I think its easier to say it like this)
- Use a **Brim** (around 5-8 mm) so it doesn't fall over
- Turn on **Organic (tree) supports** for the top vents and side rails
- Layer height: 0.2 mm (or adaptive layer height for a smoother top curve)
